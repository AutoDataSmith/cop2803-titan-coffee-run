# Assignment 6 AI Interaction Log

## Summary

This log records the main ways AI was used during Assignment 6. I did not record every small message, but I kept notes for planning decisions, debugging help, and major checkpoints.

## Major Interactions

### Assignment Review and Planning

AI helped me read through the Assignment 6 requirements and compare them to my completed Assignment 5 project. This helped me see that the new work should build on the existing login/session system instead of replacing it.

### Sprint Story and Roadmap

AI helped me draft the Sprint 3 story, acceptance criteria, and a step-by-step task list. I used this to keep the assignment organized and to avoid jumping into the code without a plan.

### Order Page and Cart Design

AI helped me think through the order page, `cart.js`, and the required `Product` and `Order` classes. We decided to use `sessionStorage` and a small cart storage helper so the cart logic would be easier to understand and possibly update in a later assignment.

### Checkout Page

AI helped me build the checkout review page after I confirmed the assignment did not require a real payment process. The page displays cart items, size, quantity, item price, line totals, and the final total.

### Testing and Debugging

AI helped me document test cases and debug issues found during browser testing. Examples included invalid quantity handling, removing cart items, empty cart behavior, checkout redirect behavior, and admin login regression testing.

### Scope Control

Some possible improvements were documented but not added, such as duplicate cart row handling and size-based pricing. AI helped me keep those as polish items instead of expanding the assignment too far.
